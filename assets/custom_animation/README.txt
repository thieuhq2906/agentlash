HƯỚNG DẪN THÊM HOẠT ẢNH TÙY CHỈNH:
======================================
Thả hình ảnh hoặc hoạt ảnh vào thư mục này để thay thế hoạt ảnh trúng đòn mặc định (POW/ZAP/CRACK).
Không cần khởi động lại ứng dụng: file mới được nhận ở cú quất tiếp theo.
Nếu có nhiều hoạt ảnh, mỗi cú quất sẽ chọn ngẫu nhiên một cái.

1. ẢNH ĐỘNG (.GIF):
   - Thả file .gif bất kỳ vào đây (ví dụ: `my_animation.gif`).
   - Ứng dụng phát toàn bộ GIF một lần tại điểm trúng roi (tối đa 3 giây).

2. CHUỖI ẢNH SEQUENCE (.PNG, .JPG):
   - Đặt tên theo thứ tự: `frame_01.png`, `frame_02.png`, `frame_03.png`...
   - Các file cùng tiền tố + số thứ tự được ghép thành một hoạt ảnh (~14 hình/giây).

3. ẢNH ĐƠN (.PNG, .JPG, .WEBP):
   - Thả file ảnh có nền trong suốt (transparent PNG) vào đây (tên không kết thúc bằng số).
   - Ứng dụng tự tạo hiệu ứng pop-up nẩy tung (elastic bounce) + rung lắc truyện tranh tại điểm quất roi!

Ảnh lớn sẽ tự thu nhỏ cho vừa khung ~320px.
Tắt hoạt ảnh tùy chỉnh: menu khay hệ thống -> Tùy Chọn Hoạt Ảnh -> "Dùng hoạt ảnh tùy chỉnh".
