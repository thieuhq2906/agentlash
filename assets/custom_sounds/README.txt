HƯỚNG DẪN THÊM ÂM THANH TÙY CHỈNH:
======================================
Thả file .wav hoặc .mp3 vào thư mục này. Khi có ít nhất 1 file, ứng dụng sẽ dùng
âm thanh của bạn thay cho âm thanh mặc định (nhiều file -> chọn ngẫu nhiên mỗi cú quất).
Không cần khởi động lại ứng dụng. Xóa hết file trong thư mục để quay về âm thanh mặc định.
